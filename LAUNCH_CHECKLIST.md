# Static website launch checklist

- [ ] Client confirms domain, logo, contact details, service content and generated imagery.
- [ ] Client confirms the FormSubmit receiving email and activates it.
- [ ] Contact and freight quote delivery tested with approval.
- [ ] Privacy notice reflects FormSubmit, the receiving mailbox and map provider.
- [ ] Approved HTTPS origin configured; production build is indexable.
- [ ] Frontend tests, build and generated-file verification pass.
- [ ] Desktop/mobile routes, forms, navigation, carousel, map, loading states and reduced motion verified.
- [ ] Complete `dist/` and matching security headers published to static hosting.
- [ ] Unknown routes return HTTP 404; sitemap, robots and metadata verified.
